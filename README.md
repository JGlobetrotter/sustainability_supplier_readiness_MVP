# Sustainability Supplier Readiness Diagnostic

A Streamlit app that assesses supplier readiness for sustainability and regulatory requirements (e.g. CSRD, HRDD).

## What it does
- Screens suppliers through a structured questionnaire  
- Generates a readiness score and risk band  
- Flags key governance and compliance gaps  
- Produces a downloadable PDF report with recommendations  

## How to run
```bash
pip install -r requirements.txt
streamlit run streamlit_app.py

usage requires licensing.
